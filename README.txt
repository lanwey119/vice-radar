VICE RADAR — Prototipo web estático
Abre index.html en un navegador. El buscador y filtros funcionan localmente. La preferencia de alertas se guarda en el navegador, no envía notificaciones.
Para publicar: subir index.html a un alojamiento estático (por ejemplo Cloudflare Pages o Netlify), conectar dominio propio y HTTPS. Para añadir contenido, actualizar el array data o publicar news.json junto a index.html con un array de objetos date (AAAA-MM-DD), cat, art, title, desc, url. El sitio carga ese archivo si está disponible. La automatización de ChatGPT entrega noticias editoriales, no modifica el alojamiento.
Antes de monetizar: redactar artículos originales completos, crear páginas individuales indexables, incorporar información real del editor, contacto, privacidad, consentimiento de cookies si procede y condiciones de afiliación. Solicitar aprobación de la red publicitaria y configurar analítica con consentimiento aplicable. Configurar un servicio de newsletter o web push con alta y baja voluntarias. No copiar artículos ni imágenes ajenas sin autorización.

VERSIÓN 2: RADAR AUTOMÁTICO
Sube el contenido de esta carpeta (incluyendo .github) a un repositorio GitHub. Activa Actions y permite escritura del workflow. Ejecuta Radar de noticias manualmente una vez. Publica el repositorio en Cloudflare Pages conectado a GitHub (sin comando de compilación, directorio raíz). Cada commit del robot puede provocar un nuevo despliegue. El horario de GitHub puede sufrir retrasos. El script recoge titulares de Google News RSS, no verifica su contenido ni redacta artículos con IA. La automatización de ChatGPT es independiente y entrega artículos para revisión; no está conectada al repositorio. No se incluyen credenciales ni anuncios reales. Antes de monetizar, añade identificación del responsable, privacidad y consentimiento donde proceda, y publica contenido editorial original. Las alertas de visitantes requieren servicio adicional.
